# AGENTS.md

Thetis — Windows SDR client for OpenHPSDR/ANAN radios (PowerSDR fork). WinForms C# UI + native C DSP. No tests, no linters. CI: GitHub Actions build only (`.github/workflows/build.yml`, runs on push to `master`/`zh-cn`).

## Build

- Windows + Visual Studio 2022 only. Open `Project Files\Source\Thetis_VS2022.sln`. No local CLI build scripts, no dotnet support.
- Always build via the solution: the C# app DllImports `wdsp.dll` / `ChannelMaster.dll` (C++, v143 toolset). A C#-only build produces an exe that fails at runtime. Also needed: `lib\fftw_x86|fftw_x64\libfftw3-3.dll` (copied by a Thetis.csproj post-build step, along with `CAT\CATStructs.xml` and `lib\Thetis-resources\calculus` — missing files do NOT fail the build).
- Output: `Project Files\bin\<x86|x64>\<Debug|Release>\`; native intermediates in `Project Files\build\` (both gitignored). Native projects write DLLs directly into the same bin dir; arch comes from property sheets `Console\Resources\Common.{Win32,x64}.user.props` (`HPSDR_PLATFORM`).
- Default target is x86 (`Any CPU` maps to x86 in the sln). x64 is configured.
- `Console\Thetis.csproj` is old-style with explicit `<Compile Include>`: new .cs/.resx files under `Console\` are not compiled until added to the csproj.
- .NET Framework 4.8, WinForms, `AllowUnsafeBlocks`, no `LangVersion` set (avoid modern C# syntax). NuGet deps are vendored in `Source\packages` via packages.config (SharpDX 4.2.0, FTD2XX.Net, WindowsFirewallHelper). Debug builds define `NEW_KEYER`; an `Interleaved` configuration exists as a TX-pipeline variant.
- CI (windows-2022) builds Release x86 and x64; WiX 3.11.2 is installed via choco for the installer project.

## Layout

- `Project Files\Source\Console\` — the app. `console.cs` is ~50k lines (main form logic). Forms have `.Designer.cs` files generated by the WinForms designer — edit in VS designer or mirror its structure.
- `Project Files\Source\wdsp\` — DSP library (C). `Project Files\Source\ChannelMaster\` — channel mixer/router (C, links wdsp). C# wrappers in `dsp.cs`, `cmaster.cs`.
- `Project Files\Source\Midi2Cat\`, `RawInput\` — C# libs referenced by Thetis.
- `Project Files\Source\Thetis-Installer\` — WiX MSI; MSI version bound from Thetis.exe FileVersion, strings in `Thetis_en-us.wxl`. (`Setup\PowerSDR Setup.vdproj` is a legacy installer, not in the sln.)
- `HPSDR\` = radio network-protocol/firmware comms; `CAT\` = CAT/serial control; `Andromeda\`, `KE9N\` = feature areas by contributor. `Skins\`, `Documentation\` = assets/docs, not code.

## Localization (zh-cn branch)

- The UI is localized to Simplified Chinese via direct string replacement (no resx satellites). All work lives on branch `zh-cn`; keep it based on `master`.
- **Encoding**: every modified `.cs`/`.resx` file must be saved as **UTF-8 with BOM** (repo files are mixed; Chinese without BOM risks mojibake under GBK locales).
- **Never translate strings that are compared in code** (`==`, `!=`, `switch (x.Text)`, `case "..."`). Known offenders: combo items added via `Items.Add`/`Items.AddRange`/enum `ToString()` (e.g. display modes `Panadapter`/`Spectrum`/`Panafall`/`Waterfall`, AGC `Med`/`High`, process priorities, regions `United States`, `Linear`/`Log`, label align `Left`/`Cntr`/`Right`/`Auto`/`Off`, meter types `Fwd Pwr`/`SWR`/`Leveler`/`Mic`, sig-gen `Radio`/`Tone`/`Sweep`), menu items wired to `mnuDSP_Click`-style text switches (only `Peak` among translated ones), `ucInfoBar` state strings `Feedback`/`FB`/`Correct`/`Correcting`, `callBox` placeholder `callsign`.
- **Never translate**: mode names (USB/LSB/CW/CWL/CWU/AM/SAM/FM/DIGL/DIGU/DRM/DSB/SPEC), band labels (160m…, VHF0:…, GEN/WWV), CAT/protocol strings (`CATCommands.cs`, `CATParser.cs`, `CATStructs.xml`, `TCIServer.cs`), SQL/XML keys/DB table names, file paths, format strings, profile name `Default`, skin names.
- **Style**: keep abbreviations + Chinese meaning (e.g. `AGC 偏移`, `VFO 同步`); UI sentences fully Chinese with Chinese punctuation.
- Combo `.Text` values are persisted in the DB by text — users upgrading from an English DB may see English values in a few combos until they change them; acceptable, do not "fix" by reverting translations.
- `Debug.WriteLine`/log-file output stays English (upstream bug-report compatibility); user-visible dialogs/labels/MessageBoxes are translated.
- Localization tooling (extract/apply/revert scripts + dicts) lives outside the repo under `C:\Users\Administrator\AppData\Local\Temp\opencode\thetis-zh\`; re-run `apply.ps1` is idempotent per file.

## Conventions

- Version bumps: `Console\AssemblyInfo.cs` AssemblyVersion (drives the installer version). Changelogs are PDFs/docx in the repo root.
- Repo root is `OpenHPSDR-Thetis\`, one level below the workspace root `D:\Project\Thetis_modify`.
- Commit messages follow `i18n(zh-CN): ...` for translation work, one concern per commit.
